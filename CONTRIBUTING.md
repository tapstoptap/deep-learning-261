# Contributing

## Workflow

1. Pull the latest `main`.
2. Create a focused branch.
3. Implement one scoped change.
4. Run the relevant checks.
5. Update documentation and AI_USAGE.md when applicable.
6. Open a pull request.
7. Request review from at least one teammate.
8. Merge only after review and verification.

## Branch naming

- feat/a1-data
- feat/a1-linear
- feat/a1-training
- fix/a1-metrics
- docs/a1-results

## Repository rules

- Do not commit datasets, credentials, local logs, or large checkpoints.
- Do not push directly to main after repository initialization.
- Do not document commands that have not been tested.
- Do not report experiments that were not run.
- Each result must identify its configuration, split, seed, checkpoint, and commit.
